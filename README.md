# Prodigy InfoTech Web Development Internship — Task 5: Weather App

A responsive weather application built with HTML, CSS, and JavaScript. It allows users to search for a city or use their device location to view current weather conditions and a seven-day forecast.

## Features
- Search weather by city name
- Optional current-location weather using browser geolocation permission
- Current temperature, feels-like temperature, humidity, wind speed, and precipitation
- Weather condition icons and descriptions
- Seven-day high/low temperature forecast
- Responsive layout for mobile and desktop
- Loading and error messages
- No API key required

## Technologies
- HTML5
- CSS3 (responsive design)
- JavaScript (Fetch API, Geolocation API)
- Open-Meteo Forecast API and Geocoding API

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser. If your browser restricts requests from local files, run a simple local server (for example, VS Code Live Server or `python -m http.server`).
3. Ensure you have an internet connection so the app can request weather data.

## Data source
Weather and geocoding data are provided by [Open-Meteo](https://open-meteo.com/). No API key is required for this project.

## Internship task
**Task 5 — Weather App:** Build a web page that fetches weather data from a weather API based on a user's location or a user-entered location, and displays current weather conditions, temperature, and related information.
